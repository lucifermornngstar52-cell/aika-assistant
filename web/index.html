Aika Assistant

Anime AI Assistant · Flutter · Android

Flutter 3.0+ Gemini 2.0 Flash GPT-4o-mini Live2D Avatar Android 6.0+
📱 Android Mobile App
This project is a Flutter/Android application. It cannot run in a web browser — it needs to be built and installed on an Android device or emulator. See the setup guide below to build and run it.

✨ Features

🤖
Dual AI Engine
Powered by Gemini 2.0 Flash and GPT-4o-mini. Vision-capable — can analyze your screen and take action.
🌸
Live2D Avatar
Interactive anime character rendered via PIXI.js and Live2D Cubism SDK inside a transparent overlay.
🎤
Voice Control
Full speech-to-text and text-to-speech. Wake word detection and natural language commands.
📱
Device Automation
Launches apps, controls volume, toggles flashlight, reads battery, performs screen taps via Accessibility.
🧠
Self-Learning
Users can teach Aika custom commands. Tracks relationships, mood, habits, and memory across sessions.
🎮
Game Helper
Monitors screen zones during gaming — alerts when HP is low, enemies appear, or events trigger.

🚀 Build & Run

1

Install Flutter SDK (3.0+)

Download from flutter.dev and add to PATH. Requires Java JDK 17 and Android Studio.

2

Install dependencies

flutter pub get
3

Connect Android device

Enable Developer Mode on your phone: Settings → About → tap Build Number 7×, then enable USB Debugging.

4

Run or build APK

# Run directly on connected device
flutter run

# Or build a release APK
flutter build apk --release

# APK output path:
build/app/outputs/flutter-apk/app-release.apk
5

API Keys

Edit lib/services/ai_service.dart and set your Gemini and OpenAI keys, or pass them via --dart-define.
