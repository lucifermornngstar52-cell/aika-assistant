Айка — AI Ассистент

Аниме AI ассистент с мощным голосовым управлением · Flutter · Android

Flutter 3.0+ Gemini 2.0 Flash GPT-4o-mini 150+ голосовых команд Live2D аватар Android 6.0+
📱 Это Android-приложение
Айка — Flutter/Android приложение. В браузере не запускается — нужно собрать APK и установить на Android телефон (Android 6.0+, API 23+).
Смотри инструкцию по сборке ниже.

✨ Возможности

🎤
150+ голосовых команд
Новый VoiceCommandProcessor обрабатывает команды мгновенно — без AI и без интернета. Фонарик, яркость, Wi-Fi, звук, приложения, таймеры, карты и многое другое.
🤖
Двойной AI: Gemini + GPT-4o
Если команда сложная — она уходит в AI. Gemini 2.0 Flash как запасной, GPT-4o-mini как основной. Vision: видит экран и выполняет задачи.
🌸
Live2D аватар
Интерактивный аниме-персонаж на PIXI.js + Live2D Cubism SDK в прозрачном оверлее поверх всех приложений. Танцует под музыку!
📱
Полное управление телефоном
Запуск 50+ приложений, яркость, Wi-Fi, Bluetooth, авиарежим, горячая точка, DND, экономия энергии, блокировка, скриншот.
📞
Звонки и сообщения
Голосовые звонки по имени, отправка SMS, сообщения в WhatsApp/Telegram/VK по голосу. Чтение уведомлений вслух.
🧠
Самообучение и память
Айка запоминает привычки, настроение, отношения. Учится новым командам: "когда я говорю [фраза] делай [действие]".
⏰
Таймеры и будильники
"Таймер на 5 минут", "Разбуди меня в 7:30", "Напомни через 10 минут" — всё понимает с первого раза.
🎮
Помощь в играх
Мониторит экран во время игры: предупреждает о мало HP, видит врагов. Записывает экран, делает скриншоты по команде.
🗺
Навигация и карты
"Проложи маршрут до Кремля", "Найди ближайшую аптеку", "Где находится [место]" — открывает Google Карты с адресом.

🏗 Архитектура голосового управления

СлойФайлОписание
1️⃣ Пробуждение wake_word_service.dart Всегда слушает «Айка» / кастомное слово. Бесконечный цикл STT.
2️⃣ Голосовые команды voice_command_processor.dart NEW 150+ команд без AI. Мгновенный ответ, работает оффлайн.
3️⃣ Телефон (legacy) phone_control_service.dart Дополнительные команды: SMS, звонки, навигация.
4️⃣ Автоматизация aika_automation_service.dart Сложные макросы, игровой мониторинг, поиск в приложении.
5️⃣ AI (GPT/Gemini) ai_service.dart Всё что не распознано локально. 60+ ACTION-тегов: приложения, яркость, Wi-Fi, YouTube-поиск, маршруты и др.
6️⃣ Исполнение device_service.dart Выполняет ACTION-теги из ответов AI. РАСШИРЕН
7️⃣ Оверлей AikaOverlayService.kt Live2D аватар поверх всех приложений. Меняет анимацию по состоянию.

🚀 Сборка и запуск

1

Установи Flutter SDK (3.0+) и Java JDK 17

Скачай с flutter.dev и добавь в PATH. Нужен Android Studio или VS Code с Flutter плагином.

2

Установи зависимости

flutter pub get
3

Подключи Android телефон

Включи режим разработчика: Настройки → О телефоне → нажми 7 раз на "Номер сборки". Затем включи «Отладка по USB».

4

Запусти или собери APK

# Запуск прямо на телефоне
flutter run

# Или собрать release APK
flutter build apk --release

# APK будет здесь:
build/app/outputs/flutter-apk/app-release.apk
5

API ключи (необязательно)

Отредактируй lib/services/ai_service.dart — вставь ключи Gemini и OpenAI. Без ключей часть AI-функций недоступна, но базовые голосовые команды работают без интернета.

6

Дай разрешения при первом запуске

✅ Микрофон — для голосового ввода
✅ Accessibility — для управления экраном
✅ Оверлей — для Live2D аватара поверх приложений
✅ Уведомления — для чтения уведомлений вслух
